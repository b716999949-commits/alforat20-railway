# الفرات موبايل — النسخة الكاملة لـ Railway

هذه نسخة من ملفات Cloudflare Pages الأصلية، مع محول محلي لـ SQLite وتشغيل Node.js 22.16+ دون خدمات Cloudflare وقت التشغيل. كل الصور والفيديوهات وواجهات الموقع مضمنة داخل المشروع. تستعيد البيانات الأولية 23 منتجًا و4 إعلانات، ولا تعيد استيراد العناصر المحذوفة بعد التهيئة الأولى. لا توجد كلمات مرور أو قواعد بيانات خاصة داخل الحزمة.

## النشر الآمن
1. ارفع **محتويات** هذا المجلد إلى مستودع GitHub خاص بك، وليس ملف ZIP وحده. تأكد من وجود Dockerfile وrailway.json في جذر المستودع.
2. اربط مستودع المصدر بخدمة Railway التي لديها قرص دائم /data. احتفظ بالخدمة القديمة وقاعدة بياناتها حتى تتأكد من النسخة الجديدة.
3. اضبط ADMIN_PASSWORD على كلمة مرور خاصة قوية من 20 حرفًا على الأقل. لا تشاركها في مستودع GitHub أو في الدردشة.
4. يستخدم التطبيق ملفًا جديدًا مستقلًا /data/alfurat-v3.sqlite3. لا تشر إلى قاعدة Python القديمة باستخدام FURAT_DB_PATH، لاختلاف جداول المصادقة. لا تحذف أي ملفات سابقة على القرص.
5. منفذ HTTP هو PORT الذي تمنحه Railway. مسار الفحص /health. بعد النشر افتح / و/admin و/api/catalog.
6. إذا كانت هناك تغييرات معلقة من محاولة النقل السابقة، فلا تعتمدها؛ ألغِها أولًا من لوحة Railway قبل ربط هذه النسخة.

## التحقق المحلي
تم التحقق من تشغيل الكتالوج (23 منتجًا، 4 إعلانات)، فتح صور المنتجات والإعلانات، صفحات الدخول والإدارة والحساب، تسجيل مدير تجريبي، رفض الوصول غير المصرح، تسجيل عميل تجريبي، حفظ الملف الشخصي، رفع واستعادة صورة، وبقاء البيانات والجلسات بعد إعادة التشغيل. الاختبارات استخدمت قاعدة بيانات مؤقتة وليس بيانات العملاء الحقيقية.

## حدود النقل
- هذه الحزمة تحفظ كامل ملفات الإصدار المرفق ووظائفه، لكن لم تُنشر على Railway بعد.
- لا توجد طلبات أو حسابات عملاء في قاعدة Cloudflare بحسب الجرد عند النقل. لا تتضمن الحزمة سجلات خاصة من نسخة Railway القديمة، التي لم تُفحص بياناتها الداخلية.
- الأسعار والتوفر في الكتالوج الأولي بحاجة إلى تأكيد صاحب المتجر. لا يمكن ضمان الوصول من كل مزود إنترنت في اليمن أو مجانية Railway بلا حدود.
